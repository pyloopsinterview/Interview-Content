## 4. Can Kafka be used without ZooKeeper?
**Answer:**  
Yes, Kafka can be used without ZooKeeper now. Earlier, Kafka depended on ZooKeeper for coordination and metadata management. With newer versions, Kafka introduced KRaft mode, which uses a Raft-based consensus internally. This removes the ZooKeeper dependency and simplifies cluster management. For new setups, KRaft mode is the recommended approach.

## 8. What is the difference between the real DOM and the React virtual DOM?
**Answer:**  
The real DOM is the actual structure of the web page maintained by the browser. Updating it directly can be slow. React uses a virtual DOM, which is a lightweight copy kept in memory. When state changes, React updates the virtual DOM first, compares it with the previous version, and updates only the changed parts in the real DOM. This makes React applications more efficient and faster.

## 9. What is state in React?
**Answer:**  
State in React is the data that belongs to a component and can change over time. It controls what is rendered on the screen. When the state changes, React automatically re-renders the component. I usually manage state using hooks like useState and useReducer in functional components.
