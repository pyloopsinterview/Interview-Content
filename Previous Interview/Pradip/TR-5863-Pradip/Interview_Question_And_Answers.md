## ✅ 1. ERP Harmonization (Post-Merger)

**Question:** Best approach to ensure minimal disruption + compliance  

**👉 Correct Answer:**  
**C. Phased migration starting with finance modules**

**Why:**
- Ensures regulatory compliance (finance first)  
- Reduces risk  
- Allows controlled transition

## ✅ 4. D365 Clinical Supply Chain Security (Multiple Choice)

**Question:** Ensure traceability + data security  

**👉 Correct Answers:**
- B. Automated exception reporting  
- C. Role-Based Access Control (RBAC)  
- D. Audit logging of data changes  
- F. End-to-end encryption  

**Why:**
- Exception reporting → issue tracking  
- RBAC → access control  
- Audit logs → traceability  
- Encryption → data protection
