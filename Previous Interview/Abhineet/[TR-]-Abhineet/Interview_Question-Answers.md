## 4. How did you structure Terraform modules?
**Answer:**
We followed a modular architecture so the infrastructure could be reusable, scalable, and easier to maintain. We separated modules based on infrastructure components such as networking, storage, compute, Kubernetes, and IAM.

For example:
- A networking module created VPCs, subnets, and routing rules.
- A storage module handled Cloud Storage buckets and BigQuery datasets.
- A Kubernetes module provisioned GKE clusters and node pools.
- IAM modules managed roles and service accounts.
