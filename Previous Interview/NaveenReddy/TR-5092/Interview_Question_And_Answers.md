# Interview Questions with Answers

## 1. Have you used any hooks in React?
Yes, I have used React Hooks extensively such as useState, useEffect, useContext, useCallback, and useMemo to manage state, side effects, shared data, and performance optimization.

## 2. How do useCallback, useMemo, and React.memo work?
- useCallback memoizes functions to prevent unnecessary re-creation.
- useMemo memoizes computed values to avoid expensive recalculations.
- React.memo prevents re-rendering of child components when props don’t change.

## 3. How did you achieve front-end performance optimization?
By reducing unnecessary re-renders, optimizing state management, implementing lazy loading, code splitting, debouncing API calls, and optimizing bundle size.

## 4. Write a function to get the output in JavaScript.
The approach is to reverse characters of each word individually while maintaining word order.

## 5. What is the approach without using map or reverse?
Traverse the string character by character, reverse characters between spaces, and rebuild the output string.

## 6. Are you aware of exception handling?
Yes. Exception handling allows graceful handling of runtime errors to prevent application crashes.

## 7. What is a Null Pointer Exception?
It occurs when an application tries to access an object or property that is null.

## 8. Why does Null Pointer Exception happen?
Due to uninitialized objects, incorrect assumptions, missing validations, or null responses from APIs.

## 9. How do you avoid Null Pointer Exceptions?
By proper initialization, null checks, defensive programming, validations, and coding standards.

## 16. Difference between procedure and function?
- Procedure performs actions and may return multiple outputs.
- Function returns a single value and is used in SQL queries.

## 17. What is reference?
A reference points to the same memory location rather than copying the value.

## 18. How does reference work?
Modifying an object through one reference reflects across all references.

## 19. Have you written PL/SQL code?

## 20. Difference between procedure and function (revisited)?
Procedures focus on actions; functions focus on returning values.

## 21. Explain reference concept again.
References allow multiple variables to access the same object in memory.
