## 4. What are the key principles of RESTful APIs?
**Answer:**  
The key principles of RESTful APIs include:
- Statelessness, where each request is independent  
- Resource-based design instead of action-based  
- Proper use of HTTP methods like GET, POST, PUT, DELETE  
- Meaningful HTTP status codes  
- Consistent request and response structures  
- API versioning to avoid breaking changes  
- Security, performance, and scalability considerations such as authentication, validation, pagination, and caching

---

## 5. What is the difference between REST API and GraphQL?
**Answer:**  
REST APIs use multiple endpoints with fixed response structures, which can lead to over-fetching or under-fetching of data. GraphQL uses a single endpoint where the client specifies exactly what data it needs, reducing unnecessary data transfer. REST is simpler, easier to cache, and widely used for CRUD operations, while GraphQL is better suited for complex UI-driven data requirements and reducing network calls.
