## 11. What are the advantages of ORM?
**Answer:**
- Improves developer productivity (no need for raw SQL)  
- Provides database abstraction  
- Enhances code readability and maintainability  
- Protects against SQL injection  
- Supports migrations and relationship handling  

---

## 12. What is Django QuerySet?
**Answer:**
QuerySet is a Django ORM feature used to interact with the database.

Advantages:
- Lazy evaluation (improves performance)  
- Query chaining for complex queries  
- Cleaner and more readable code  
- Integration with Django models
