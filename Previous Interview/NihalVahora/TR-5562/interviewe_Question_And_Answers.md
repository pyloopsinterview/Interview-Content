## 1. Have you done migration on any of the cloud platforms?

**Answer:**

Yes, I have worked on large-scale cloud migration projects, specifically migrating legacy healthcare systems into Dynamics 365 Customer Service Online on Microsoft Azure.

At Magellan Health, we consolidated multiple legacy case management systems into a centralized Dynamics 365 platform. This involved migrating member data, provider records, historical cases, SLAs, activities, and attachments.

We used Azure-based ETL processes, including KingswaySoft and SSIS, for structured data migration. The process included:

* Data assessment and profiling
* Mapping documentation
* Data cleansing and transformation
* Test migrations
* Reconciliation reporting
* Final production cutover

Because it was healthcare data, compliance, security, and data integrity were critical. We ensured no data loss and validated relationships post-migration.

---

## 2. Which cloud platform was used?

**Answer:**

We migrated to Microsoft Azure along with Dynamics 365 Online.

Dynamics 365 was deployed as a SaaS solution, and we used Azure services for:

* Secure integrations via REST APIs
* Azure AD authentication and role-based access
* Middleware components
* Data migration pipelines

The entire ecosystem was built within the Microsoft stack.

## 3. You’ve done large-scale healthcare data migration into CRM on Azure, correct?

**Answer:**

Yes, that’s correct.

It was a large-scale healthcare data migration involving thousands of daily case transactions. We migrated structured and relational data while maintaining compliance and audit requirements.

Performance and scalability were carefully monitored during and after go-live.
